## 第2部分 总体设计

### 2.1 硬件运行环境

单机 Web 应用，无特殊硬件要求：普通 PC（2 核 CPU / 4 GB 内存 / 1 GB 可用磁盘）即可完成开发、演示与课程评审。

### 2.2 软件运行环境

| 项 | 选型 | 说明 |
|----|------|------|
| 语言 | Python 3.10+ | 类型注解采用 `typing`（str/int/bool/datetime/List/Optional） |
| Web 框架 | Flask 3.x | 轻量路由 + 视图；分层由本设计自行约束 |
| 模板引擎 | Jinja2（随 Flask） | 渲染三个页面 |
| 数据库 | SQLite 3 | 文件型数据库，无需独立服务 |
| 会话 | Flask session | 承载登录态（当前会员） |

### 2.3 子系统清单（逻辑分层）

| 层 | 类 | 职责 |
|----|----|------|
| 界面层 «boundary» | 检索页面、详情页面、登录页面 | 接收输入、展示结果与提示；对应 Flask 路由 + Jinja2 模板 |
| 控制层 «control» | 检索控制器、帖子控制器、评论控制器、回复控制器、登录控制器 | 每用例一个控制器，编排流程、应用业务规则 |
| 数据访问层 «DAO» | 帖子DAO、评论DAO、会员DAO | 封装 SQLite 读写与分页 SQL |
| 实体 / 值对象 | 帖子、评论、会员；分页结果 | 领域数据（纯数据类）+ 领域校验（会员.校验密码）+ 分页值对象 |

依赖方向：界面层 → 控制层 → 数据访问层 → 实体/值对象；不出现反向或跨层调用。

### 2.4 功能模块清单

| 用例 | 功能模块 | 参与类（设计级） | 入口 |
|------|----------|------------------|------|
| UC1 检索帖子 | 按标题关键词检索 | 检索页面·检索控制器·帖子DAO·帖子 | 检索页面 |
| UC2 阅读帖子详细内容 | 帖子详情 + 评论 | 详情页面·帖子控制器·帖子DAO·评论控制器·评论DAO | 详情页面 |
| UC3 浏览评论 | 每页 20 条分页浏览 | 详情页面·评论控制器·评论DAO·分页结果 | 详情页面评论区 |
| UC4 回复帖子 | 登录判定 + 回复 + 刷新 | 详情页面·回复控制器·登录控制器·评论控制器·评论DAO·评论 | 详情页面回复面板 |
| UC5 登录 | 凭证校验 + 建立登录态 | 登录页面·登录控制器·会员DAO·会员 | 登录页面 |

## 第3部分 数据库设计

### 3.1 数据库表名列表

| 表名 | 对应实体 | 说明 |
|------|----------|------|
| member | 会员 | 注册用户账号 |
| post | 帖子 | 帖子正文单元 |
| comment | 评论 | 帖子回复（回复即评论，假设 1） |

### 3.2 数据库表关系

```
member 1 ──── 0..* post      （作者）
member 1 ──── 0..* comment   （作者）
post   1 ──── 0..* comment   （组合：删除帖子级联删除其评论）
```

### 3.3 数据库表的详细清单

**3.3.1 member（会员表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 会员ID |
| username | TEXT | NOT NULL UNIQUE | 用户名（登录凭证） |
| password | TEXT | NOT NULL | 密码（实现阶段用 werkzeug 哈希存储，不存明文） |

**3.3.2 post（帖子表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 帖子ID |
| title | TEXT | NOT NULL | 标题（检索范围，B-1） |
| content | TEXT | NOT NULL | 内容 |
| created_at | DATETIME | NOT NULL | 发表时间 |
| author_id | INTEGER | NOT NULL, REFERENCES member(id) | 作者 |

**3.3.3 comment（评论表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 评论ID |
| content | TEXT | NOT NULL | 内容 |
| created_at | DATETIME | NOT NULL | 发表时间（倒序分页依据，假设 2） |
| post_id | INTEGER | NOT NULL, REFERENCES post(id) ON DELETE CASCADE | 所属帖子 |
| author_id | INTEGER | NOT NULL, REFERENCES member(id) | 作者 |

## 第4部分 典型的子系统设计（用例实现）

> 每个用例：概述（参与类）→ 顺序图描述（消息链走查）→ 活动图描述（有则引用）。顺序图中的全部生命线均出现在 `06-design-class.drawio`。

### 4.1 UC1 检索帖子

**4.1.1 概述**：检索页面 → 检索控制器 → 帖子DAO → 帖子。检索范围仅限帖子标题（B-1），结果项为标题、作者、发表时间。

**4.1.2 顺序图描述**（`检索帖子-sequence-design.drawio`）：
1. 用户在检索页面输入关键词提交；2. 页面调用 检索控制器.检索帖子(关键词)；3. 控制器调用 帖子DAO.按标题匹配(关键词)；4. DAO 返回 `List[帖子]`；alt [存在匹配帖子] → 页面展示匹配列表；[无匹配 — A-3] → 提示"未找到相关帖子"。

**4.1.3 活动图描述**：无（流程为线性 + 单分支，顺序图 alt 已充分表达）。

### 4.2 UC2 阅读帖子详细内容

**4.2.1 概述**：详情页面 → 帖子控制器 → 帖子DAO；评论随详情一并加载（«include» UC3）；«extend» UC4 以 ref 片段引用。

**4.2.2 顺序图描述**（`阅读帖子详细内容-sequence-design.drawio`）：
1. 用户点击帖子标题；2. 页面调用 帖子控制器.查看帖子详情(帖子ID)；3. 控制器调用 帖子DAO.按ID查询(帖子ID)；alt [帖子不存在或已删除 — A-2] → 提示；[帖子存在] → 4. 控制器调用 评论控制器.加载评论（«include» UC3，分页查询第 1 页）；5. 返回帖子详情 + 分页结果，页面展示标题、内容、作者、发表时间与评论。ref 片段引用 UC4（扩展点"用户选择回复"）。

**4.2.3 活动图描述**：无（分支由顺序图 alt 表达）。

### 4.3 UC3 浏览评论

**4.3.1 概述**：详情页面 → 评论控制器 → 评论DAO → 分页结果（条目为 `List[评论]`）。评论实体为被动数据，不单设生命线；每页固定 20 条（B-1），按发表时间倒序（假设 2）。

**4.3.2 顺序图描述**（`浏览评论-sequence-design-v3.drawio`）：
1. 页面调用 评论控制器.浏览评论(帖子ID, 页码=1)；2. 控制器调用 评论DAO.分页查询(帖子ID, 1, 20)，返回 分页结果；alt [评论总数 ≤ 20 — A-1] → 展示第 1 页（无翻页控件）；[评论总数 > 20] → 展示第 1 页 + 翻页控件，且 **loop [用户选择翻页] 嵌套于该分支内**；loop 内 alt [目标页超出范围 — A-2/A-3] → 对应按钮不可用；[目标页有效] → 按目标页码重新分页查询并展示。

**4.3.3 活动图描述**：无（多级分支与循环由顺序图嵌套片段表达；v3 已修正帧包含关系）。

### 4.4 UC4 回复帖子

**4.4.1 概述**：详情页面 → 回复控制器 → 登录控制器（判定登录态）/ 评论控制器（刷新）/ 评论DAO（保存）。B-1 系统自动判定登录状态；回复以新 评论 保存（假设 1）。

**4.4.2 顺序图描述**（`回复帖子-sequence-design.drawio`）：
1. 用户点击"回复"（UC2 扩展点）；2. 回复控制器调用 登录控制器.判定登录状态()；alt [未登录 — A-2] → 提示"请先登录"并转 UC5（ref），成功后返回原帖；[已登录] → 展示回复输入框；3. 用户输入内容提交，回复控制器调用 评论DAO.保存(评论)；alt [内容为空 — A-4] → 提示后回到输入；[内容有效] → 保存成功；4. 回复控制器经 评论控制器 刷新评论列表（分页查询第 1 页），新回复显示于评论区首位。

**4.4.3 活动图描述**（`UC4-activity.drawio`）：4 泳道（用户/详情页面/控制层/评论DAO），2 判定（登录状态、回复内容），守卫 [未登录 — A-2]、[已登录]、[内容为空 — A-4]、[内容有效]；内容为空回环至输入；"转 UC5 登录"为调用行为动作。

### 4.5 UC5 登录

**4.5.1 概述**：登录页面 → 登录控制器 → 会员DAO → 会员。登录态 = 登录控制器.当前会员（Flask session 承载）。

**4.5.2 顺序图描述**（`登录-sequence-design.drawio`）：
1. 游客进入登录界面；2. 提交用户名与密码；3. 登录控制器.校验凭证 → 会员DAO.按用户名查询 → 会员.校验密码；loop [凭证错误时重新输入] 内 alt [凭证错误 — A-4] → 提示并回到第 2 步；[凭证正确] → 建立登录态（自消息）；4. 返回登录前的浏览页面（被引导场景返回原帖）。

**4.5.3 活动图描述**（`UC5-activity.drawio`）：4 泳道（游客/登录页面/登录控制器/会员DAO·会员），守卫 [凭证错误 — A-4]、[凭证正确]；凭证错误回环至"输入用户名与密码"。

## 第5部分 页面模块设计

> 三个页面均为 Flask 路由 + Jinja2 模板；提交动作经 POST 路由转发至控制器。

### 5.1 检索页面：`/search`

- **参数**：`keyword`（标题关键词，字符串）。
- **调用背景**：游客/会员主动检索，或从其它入口跳转。
- **页面设计**：顶部检索输入框与"检索"按钮；下方结果列表（标题、作者、发表时间）或"未找到相关帖子"提示。
- **调用描述**：GET 展示检索界面；GET/POST 带 `keyword` → 检索控制器.检索帖子() → 渲染结果列表。结果分页规则待定（需求未说明，暂不分页）。

### 5.2 详情页面：`/post/<int:post_id>`

- **参数**：`post_id`（帖子ID）；翻页参数 `page`（页码）；回复参数 `content`（回复内容）。
- **调用背景**：用户点击检索结果中的标题（或其他入口）；UC4 扩展点"用户选择回复"在本页触发。
- **页面设计**：标题、内容、作者、发表时间；评论区（每页 20 条 + 上一页/下一页控件）；回复输入框与"回复"按钮。
- **调用描述**：GET → 帖子控制器.查看帖子详情() + 评论控制器.浏览评论(第 1 页)；翻页 GET（带 `page`）→ 评论控制器.浏览评论(目标页码)；回复 POST → 回复控制器（判定登录态 → 提交回复 → 刷新评论列表）。

### 5.3 登录页面：`/login`

- **参数**：`username`、`password`（登录凭证）；可选 `next`（登录后返回的页面）。
- **调用背景**：游客主动登录；或回复帖子被引导（A-2，登录后返回原帖）。
- **页面设计**：用户名、密码输入框与"登录"按钮；错误提示"用户名或密码错误"。
- **调用描述**：GET 展示表单；POST → 登录控制器.校验凭证() → 成功建立登录态并跳转回 `next` 页，失败提示并留在本页。

## 第6部分 数据访问（DAO）设计

> 无 ORM：三个 DAO 以 `sqlite3` 直连实现，SQL 要点如下。

### 6.1 帖子DAO

| 方法 | SQL 要点 |
|------|----------|
| 按标题匹配(关键词) | `SELECT id, title, created_at, author_id FROM post WHERE title LIKE '%关键词%'`（仅标题，B-1） |
| 按ID查询(帖子ID) | `SELECT * FROM post WHERE id = ?`，无记录返回 `None`（A-2 判定依据） |

### 6.2 评论DAO

| 方法 | SQL 要点 |
|------|----------|
| 分页查询(帖子ID, 页码, 每页条数) | `SELECT * FROM comment WHERE post_id = ? ORDER BY created_at DESC LIMIT 每页条数 OFFSET (页码-1)*每页条数`；同查 `COUNT(*)` 得总数，组装 分页结果 |
| 统计(帖子ID) | `SELECT COUNT(*) FROM comment WHERE post_id = ?` |
| 保存(评论) | `INSERT INTO comment(content, created_at, post_id, author_id) VALUES (?, ?, ?, ?)` |

### 6.3 会员DAO

| 方法 | SQL 要点 |
|------|----------|
| 按用户名查询(用户名) | `SELECT * FROM member WHERE username = ?`，无记录返回 `None`（凭证错误判定依据） |

## 第7部分 接口设计

### 7.1 用户接口

三个页面（检索页面 / 详情页面 / 登录页面），见第 5 部分。

### 7.2 外部接口

无（单机演示系统，不接入第三方服务）。

### 7.3 内部接口（关键方法签名）

| 类 | 方法 | 前置条件 | 后置条件 |
|----|------|----------|----------|
| 检索控制器 | `检索帖子(关键词: str) -> List[帖子]` | 关键词非空 | 返回匹配帖子列表（可为空列表） |
| 帖子控制器 | `查看帖子详情(帖子ID: int) -> Optional[帖子]` | 帖子ID 合法 | 返回帖子或 None（A-2） |
| 评论控制器 | `浏览评论(帖子ID: int, 页码: int) -> 分页结果` | 帖子存在、页码 ≥ 1 | 返回分页结果；每页条数 = 20（类常量） |
| 回复控制器 | `提交回复(帖子ID: int, 会员ID: int, 内容: str) -> bool` | 已登录、内容非空 | 保存评论成功返回 True；空内容返回 False（A-4） |
| 回复控制器 | `刷新评论列表(帖子ID: int) -> 分页结果` | 保存成功 | 返回第 1 页分页结果 |
| 登录控制器 | `校验凭证(用户名: str, 密码: str) -> bool` | — | 凭证正确返回 True 并建立登录态 |
| 会员DAO | `按用户名查询(用户名: str) -> Optional[会员]` | — | 返回会员记录或 None |
| 评论DAO | `分页查询(帖子ID: int, 页码: int, 每页条数: int) -> 分页结果` | 页码 ≥ 1 | «创建» 分页结果（条目: List[评论]） |
| 会员 | `校验密码(密码: str) -> bool` | 会员记录存在 | 密码匹配返回 True |

## 第8部分 角色授权设计

| 功能 | 游客 | 会员 |
|------|------|------|
| UC1 检索帖子 | ✓ | ✓ |
| UC2 阅读帖子详细内容 | ✓ | ✓ |
| UC3 浏览评论 | ✓ | ✓ |
| UC4 回复帖子 | ✗（点击回复 → 判定未登录 → 引导至 UC5 登录后继续） | ✓ |
| UC5 登录 | ✓（建立登录态，成为会员） | —（已登录） |

- 授权判定机制：回复控制器委托 登录控制器.判定登录状态()（读取 Flask session 中当前会员），系统自动判定（B-1），无需用户手动声明。
- 注册/找回密码不在本用例模型范围（假设 4），会员账号经外部途径预置。

## 第9部分 系统错误处理

### 9.1 出错信息

| 场景 | 提示 | 处理 |
|------|------|------|
| 检索无匹配（UC1 A-3） | "未找到相关帖子" | 用例终止 |
| 帖子不存在或已删除（UC2 A-2） | "帖子不存在或已删除" | 用例终止 |
| 评论 ≤ 20（UC3 A-1） | 不显示翻页控件 | 正常分支 |
| 末页"下一页"/首页"上一页"（UC3 A-2/A-3） | 对应按钮不可用 | 不发起查询 |
| 回复时未登录（UC4 A-2） | "请先登录" | 转 UC5，成功后返回原帖 |
| 回复内容为空（UC4 A-4） | "回复不能为空" | 回到输入 |
| 凭证错误（UC5 A-4） | "用户名或密码错误" | 回到重新输入（失败次数不限，假设 6） |

### 9.2 故障预防与补救

- 输入校验：回复内容提交前在控制器校验非空；关键词非空。
- 分页边界：评论控制器按总数与页码计算总页数，越界请求不发起（A-2/A-3）。
- 数据完整性：外键约束保证评论/帖子引用有效；删除帖子级联删除评论（组合）。
- 登录态：session 失效后按未登录处理（A-2 路径兜底）。

### 9.3 系统维护设计

- SQLite 数据文件定期备份（复制文件即可）。
- 配置集中于 Flask 配置项（数据库路径、每页条数常量、密钥）。
- 异常统一捕获并返回友好提示（对应 9.1 出错信息），记录日志。
