# 博客系统 · 浏览帖子 — 用例规格说明

> 需求模型 Stage 1 · 对应用例图：`01-usecase.puml` / `01-usecase.drawio`
> 模板依据：《UML建模课件·第4章 用例图》slide 28"用例文档"表（用例名称/编号/参与者/描述/触发器/前置/后置/基本事件流/扩展事件流/结论/数据需求/业务规则）；扩展流编号按课程惯例 `A-步骤号`（A-2 = 主流程步骤 2 的替代流程）。

## 参与者

| ID | 参与者 | 说明 |
|----|--------|------|
| A1 | 会员 | 已注册并登录的用户，可回复帖子 |
| A2 | 游客 | 未注册或未登录的访问者，可检索、阅读、浏览评论；回复时被引导登录 |

## UC1 检索帖子

| 字段 | 内容 |
|------|------|
| 用例编号 | UC1 |
| 参与者 | 会员（A1）、游客（A2） |
| 用例描述 | 用户按帖子标题关键词检索帖子，获得匹配的帖子列表 |
| 触发器 | 用户输入标题关键词并提交检索时 |
| 前置条件 | 无（未登录也可检索） |
| 后置条件 | 检索结果（列表或空结果提示）已呈现 |
| 结论 | 系统展示检索结果列表或"未找到"提示时，用例结束 |

**基本事件流**

1. 用户输入帖子标题关键词，提交检索。
2. 系统按标题匹配帖子。
3. 系统展示匹配帖子列表（标题、作者、发表时间）。

**扩展事件流**

- A-3 不存在匹配帖子 → 系统提示"未找到相关帖子"，用例终止。

**数据需求**

- D-1 检索关键词：帖子标题的部分或完整文本。
- D-2 列表项：标题、作者、发表时间。

**业务规则**

- B-1 检索范围仅限帖子标题，不含正文与作者（需求限定）。

**待定问题**

- 检索结果列表的分页规则未说明（是否同为每页 20 条）。

## UC2 阅读帖子详细内容

| 字段 | 内容 |
|------|------|
| 用例编号 | UC2 |
| 参与者 | 会员（A1）、游客（A2） |
| 用例描述 | 用户打开一篇帖子，阅读其详细内容（含评论信息） |
| 触发器 | 用户点击帖子标题（来自检索结果或其他入口）时 |
| 前置条件 | 目标帖子存在 |
| 后置条件 | 帖子详情已完整呈现 |
| 结论 | 帖子详情完整呈现，或系统提示帖子不存在时，用例结束 |

**基本事件流**

1. 用户点击帖子标题。
2. 系统展示帖子详细内容：标题、内容、作者、发表时间、评论信息。
3. 系统按每页 20 条分页展示评论（`<<include>>` UC3 浏览评论）。

**扩展事件流**

- A-2 帖子已被删除 → 系统提示"帖子不存在或已删除"，用例终止。

**扩展点**

- 用户选择回复 —— 被 `UC4 回复帖子` 以 `<<extend>>` 扩展；触发条件：用户点击"回复"。

**数据需求**

- D-1 帖子详情 = 标题、内容、作者、发表时间、评论信息。

**业务规则**

- B-1 评论信息是帖子详情的组成部分，随详情一并展示（分页规则见 UC3）。

**待定问题**

- 帖子内容是否支持富文本/多页阅读。

## UC3 浏览评论

| 字段 | 内容 |
|------|------|
| 用例编号 | UC3 |
| 参与者 | 会员（A1）、游客（A2）（随 UC2 被包含执行） |
| 用例描述 | 按每页 20 条分页浏览帖子的评论，可前后翻页 |
| 触发器 | 帖子详情展示评论信息时（由 UC2 `<<include>>` 触发） |
| 前置条件 | 正在查看某帖子详情 |
| 后置条件 | 用户可翻阅该帖全部评论 |
| 结论 | 用户停止翻页或离开帖子详情页时，用例结束 |

**基本事件流**

1. 系统按每页 20 条展示第一页评论。
2. 用户选择"下一页"→ 系统展示下一组 20 条评论。
3. 用户选择"上一页"→ 系统展示上一组 20 条评论。

**扩展事件流**

- A-1 评论总数 ≤ 20 → 不显示翻页控件。
- A-2 已处于最后一页 → "下一页"不可用。
- A-3 已处于第一页 → "上一页"不可用。

**业务规则**

- B-1 每页固定展示 20 条评论。

**待定问题**

- 评论排序规则（假设按发表时间倒序）；评论是否支持楼层嵌套。

## UC4 回复帖子

| 字段 | 内容 |
|------|------|
| 用例编号 | UC4 |
| 参与者 | 会员（A1）；游客经扩展流 A-2 转登录后以会员身份继续 |
| 与 UC2 的关系 | `<<extend>>` 扩展 UC2 阅读帖子详细内容；扩展点"用户选择回复" |
| 用例描述 | 已登录会员对帖子发表回复，回复作为评论追加展示 |
| 触发器 | 用户在帖子详情页点击"回复"（触发 UC2 扩展点）时 |
| 前置条件 | 目标帖子存在 |
| 后置条件 | 回复已保存，并作为评论信息展示于帖子详情 |
| 结论 | 回复保存成功并展示，或用户放弃回复时，用例结束 |

**基本事件流**

1. 用户在帖子详情页点击"回复"。
2. 系统判定用户登录状态。
3. 已登录 → 系统展示回复输入框。
4. 会员输入回复内容并提交。
5. 系统保存回复，刷新评论列表（新回复出现在列表中）。

**扩展事件流**

- A-2 未登录 → 系统提示"请先登录"，转至 UC5 登录；登录成功后返回原帖，可继续回复。
- A-4 回复内容为空 → 系统提示"回复不能为空"。

**数据需求**

- D-1 回复内容：文本，保存后追加为该帖评论信息。

**业务规则**

- B-1 系统自动判定登录状态，无需用户手动声明。

**待定问题**

- 回复内容长度限制；敏感词过滤；是否需要审核。

## UC5 登录

| 字段 | 内容 |
|------|------|
| 用例编号 | UC5 |
| 参与者 | 游客（A2） |
| 用例描述 | 游客通过用户名密码验证建立登录态，成为会员 |
| 触发器 | 游客主动选择"登录"，或回复帖子被系统引导至此时 |
| 前置条件 | 用户未登录；已拥有账号（注册不在本用例模型范围） |
| 后置条件 | 用户以会员身份处于登录态 |
| 结论 | 登录态建立并返回原页面，或用户放弃登录时，用例结束 |

**基本事件流**

1. 用户进入登录界面（主动进入或被引导进入）。
2. 系统要求输入用户名与密码。
3. 用户提交凭证。
4. 系统校验凭证正确，建立登录态。
5. 系统返回登录前的浏览页面（被引导的场景返回原帖）。

**扩展事件流**

- A-4 凭证错误 → 系统提示"用户名或密码错误"，回到步骤 2。

**待定问题**

- 登录失败次数是否受限；注册、找回密码流程不属本用例模型。

## 术语表

| 术语 | 定义 |
|------|------|
| 帖子 | 会员发表的正文单元，含标题、内容、作者、发表时间、评论信息 |
| 评论 | 附于帖子的回复信息，按每页 20 条分页展示 |
| 回复 | 会员对帖子追加评论的动作及其内容 |
| 会员 | 已注册并登录的用户 |
| 游客 | 未注册或未登录的访问者 |
| 登录态 | 系统可判定"用户已登录"的状态 |
| 分页 | 评论按每页 20 条展示，可前后翻页 |

## 假设清单

1. "回复"以评论形式追加展示（与评论共用评论区，不另设板块）。
2. 评论默认按发表时间倒序。
3. 检索结果列表项为标题、作者、发表时间。
4. 会员身份经注册获得；注册/找回密码不属于本用例模型范围。
5. 评论不分楼层嵌套。
6. 登录失败不限制尝试次数。

## 未覆盖需求

- 发帖、编辑/删除帖子、用户注册、管理端功能——均不在"浏览帖子"需求内，留待后续增量。
